# bdt-arena-docker

A Dockerized **Web + Android** gaming and simulated trading platform tailored for Bangladesh (`BDT ৳`), backed by a standalone PostgreSQL database and ready for non-Azure free-tier cloud deployment.

### Key Features
- **Games & Trading:** Ludo, Chess, RNG mini-games, Currency Pair (FX) simulator, and Gold (`XAU`) trade simulator.
- **BD Wallet Rails:** Deposit and withdrawal state machine supporting **bKash** and **Nagad** (sandbox/mock ready).
- **Cross-Platform:** Responsive Web UI with direct **Android APK** & app store download links.
- **Containerized Stack:** Multi-stage Docker builds with standalone PostgreSQL persistence.
